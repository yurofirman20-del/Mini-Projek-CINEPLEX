🎬 CINEPLEX - Movie Streaming Website

📌 About Project

CINEPLEX is a movie streaming website interface designed to provide users with an enjoyable experience when discovering movies and exploring movie details.

This project consists of two main pages: a homepage for browsing movies and a detail page for viewing information about a selected movie.

📄 Pages

1. Homepage

The homepage provides:

Movie navigation menu.

Search movie input.

Trending Now movie section.

Browse Genres section.

New Releases section.

Movie ratings.

Footer with platform information and subscription form.

2. Movie Detail Page

The movie detail page provides:

Movie title and background banner.

Movie information (year, genre, and duration).

Movie synopsis.

Play Movie and My List buttons.

Trailers & Clips section.

Cast & Crew information.

Average movie rating.

Movie release date and box office information.

Recent Reviews section.

Recommended movies.

🛠️ Tech Stack

HTML5

CSS3

Tailwind CSS

JavaScript (not implemented in the current HTML pages)

🚀 How to Run

Clone or download this repository.

Open the project folder.

Make sure all required images and CSS files are available.

Open Homepage.html in your browser.

Click on a movie card to navigate to the movie detail page.

🔗 Page Navigation

Homepage: Homepage.html

Movie Detail: halaman2.html

🎯 Project Goals

The goal of this project is to practice frontend web development, including:

Building website layouts using HTML.

Styling components with CSS and Tailwind CSS.

Creating movie cards and content sections.

Organizing website assets.

Connecting multiple HTML pages through navigation.
